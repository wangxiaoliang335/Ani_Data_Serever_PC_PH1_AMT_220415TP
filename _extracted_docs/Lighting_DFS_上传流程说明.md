# Lighting 点灯检测 DFS 上传业务说明

## 1. 概述

点灯检测完成后，需要将检测结果上传至 DFS 系统，用于生产数据追溯和品质管理。

---

## 2. 触发时机

**触发点：点灯检设备发送 FN$ 消息并处理完成时**

```
点灯检设备 → 发送 FN$ 消息 (包含完成的治具号)
        ↓
解析 FN$ 获取治具号列表
        ↓
根据治具号查询检测结果
        ↓
同时执行：
  ① 写入 PLC 检测结果和缺陷码
  ② 上传 DFS 文件
```

---

## 3. 数据查询

### 3.1 需要查询的数据

| 数据项 | 来源表 | 用途 |
|--------|--------|------|
| UniqueID | ivs_lcd_idmap | 产品唯一标识 |
| ScreenID / Barcode | ivs_lcd_idmap | 玻璃条码，用于文件命名 |
| MarkID | ivs_lcd_idmap | 治具号 |
| 检测结果 | IVS_LCD_InspectionResult | OK/NG、缺陷代码、等级、检测时间 |
| 缺陷列表 | IVS_LCD_AOIDefect | 各缺陷的代码和等级 |

### 3.2 查询条件

```
根据治具号 (FixtureNo) 查询
  ↓
从 ivs_lcd_idmap 获取 UniqueID、ScreenID、MarkID
  ↓
用 UniqueID 查询检测结果表
  ↓
用 UniqueID 查询缺陷详情表
```

---

## 4. 数据处理

### 4.1 写入 PLC

**写什么：**

| 数据类型 | 内容 | 备注 |
|----------|------|------|
| 主结果 | OK / NG | 良品写入 OK，异常写入 NG |
| 缺陷代码 | 如 BD、LD、MU 等 | 最多发送 N 个（可配置） |
| 缺陷等级 | 如 A、B、C、G | 取第一个缺陷的等级 |
| 写入完成标志 | Bit 置位 | 通知 PLC 数据已写入 |

### 4.2 上传 DFS

**上传什么：**

| 字段 | 内容 | 说明 |
|------|------|------|
| PanelID | 玻璃条码 | 文件命名 + 目录结构 |
| FpcID | 玻璃条码 | 同 PanelID |
| 治具号 | 01~04 | 对应哪个治具 |
| 通道号 | 0~3 | 工位索引 |
| 工位号 | 1~4 | 工位编号 |
| 点灯结果 | OK / NG | 最终判定结果 |
| 开始时间 | 时间戳 | 检测开始时刻 |
| 结束时间 | 时间戳 | 检测结束时刻 |
| 设备类型 | 固定值 | 表示点灯设备 |

---

## 5. DFS 文件格式

### 5.1 文件命名

```
<PanelID>.csv
示例: 138766A001.csv
```

### 5.2 目录结构

```
本地存储:
  <DFS共享目录>\<日期>\<PanelID>\LUMITOP\<PanelID>.csv

远程上传 (生产环境):
  \\<DFS服务器>\module\<设备ID>\<日期>\<PanelID前5位>\<PanelID前8位>\<PanelID>\Data\<PanelID>.csv

测试模式:
  D:\TEST\<PanelID>.csv
```

### 5.3 CSV 内容示例

```
PanelID,FpcID,IndexNum,ChNum,StageNum,Lumitop,StartTime,EndTime,TypeNum
138766A001,138766A001,01,0,1,OK,2026-03-22 10:30:00,2026-03-22 10:30:15,4
138766A002,138766A002,02,1,2,NG,2026-03-22 10:30:02,2026-03-22 10:30:18,4
```

## 6. PLC 与 DFS 的关系

| 项目 | PLC 写入 | DFS 上传 |
|------|----------|----------|
| 是否必须 | 是（主流程需要） | 是（数据追溯需要） |
| 是否依赖 PLC 连接 | ✅ 依赖 | ❌ 不依赖 |
| 是否依赖数据库 | ❌ 不依赖 | ❌ 不依赖 |
| 处理方式 | 同步，立即完成 | 异步，队列+后台线程 |
| 失败影响 | PLC 流程卡住 | 数据无法追溯 |

**结论：DFS 上传是独立的后台任务，不受 PLC 连接状态影响。**

## 7. 测试模式配置

| 配置项 | 作用 | 测试时建议 |
|--------|------|-----------|
| DFS 测试模式 | 文件保存到 D:\TEST，不上传服务器 | ✅ 勾选 |
| 点灯全部 PASS | 模拟良品结果 | 按需勾选 |
| 跳过 PLC | 不写入 PLC | ✅ 勾选（无 PLC 时） |

## 9. 注意事项

1. **PLC 和 DFS 可并行执行**：不互相等待
2. **DFS 是异步上传**：入队后由后台线程处理，不阻塞主流程
3. **PanelID 必须有效**：否则该条数据会被跳过
4. **测试模式避免误传**：模拟测试时务必启用 DFS 测试模式
5. **缺陷码数量可配置**：由系统参数控制最多发送几条缺陷
6. **良品等级默认 G**：没有缺陷时写入 OK 等级（如 "G"）
